Walking footsteps / হাঁটার পায়ের শব্দ

One short step sound (about 0.1-0.3 s). You can put SEVERAL files: the game picks one at random for each step. / একটা পায়ের শব্দ। একাধিক ফাইল দিলে প্রতি পায়ে এলোমেলো একটা বাজবে।

Put your file here: .ogg (best), .wav or .mp3.
This folder is EMPTY of sound files = the default sound (made by code) plays.
ম্যাপে ফাইল দিলে ওই ফাইল বাজবে, না দিলে ডিফল্ট সাউন্ড।
